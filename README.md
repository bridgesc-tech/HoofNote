# HoofNotes

HoofNotes is a phone app for keeping farm animal records. Add an animal, then track health checks, weights, vaccinations, deworming, and breeding as time goes on.

Records stay on the phone. Export a backup from More if you change phones.

## Animal profile

Each animal has a type, name, breed, color, ID number, and date of birth. Types are Dairy Cow, Beef Cow, Horse, Pig, Goat, Chicken, Lamb, and Rabbit.

On the profile:

- Health checks store a date and notes.
- Weight checks store a date, weight, and notes.
- Vaccinations and deworming store the product, amount, route, who gave it, notes, and the next due date. Add a reminder email and use Email reminder to open a message for that due date.
- Breeding stores Natural Cover or AI, the breeder, and the animal bred with.

## Install

This is a PWA. Host the folder on GitHub Pages from the `main` branch, root folder.

On iPhone: open the site, tap Share, then Add to Home Screen. On Android: use the browser menu, then Install app or Add to Home screen. Open it once while online. After that it can open without service.
